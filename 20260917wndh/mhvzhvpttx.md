# 【原创】生化妊娠，您了解多少？

> 更新时间：2026-09-17 (UTC+8)

**一、生化妊娠的定义**

受精卵在受精后第6 -7 d开始着床，大约在第9 d滋养层细胞分化为细胞滋养细胞和合体滋养细胞，并开始分泌人绒毛膜促性腺激素(HCG) ，第11-12 d 完成。着床经历定位、附着及植入3个阶段。

在植入后任何环节出现问题，都可能导致着床最终失败。临床上表现为血清 HCG 大于正常值， 但超声检查宫腔内外均未见到孕囊， 然后妊娠状态自然终止， 通常称为生化妊娠( biochemical pregnancy) 又称为不明部位妊娠、隐匿性流产。

**二、生化妊娠的原因是什么？**

关于生化妊娠的具体病因目前尚不清楚。 

1.一般认为导致生化妊娠的原因多为胚胎染色体异常以及胚胎本身质量不好，使其自然地淘汰。除此之外，生化妊娠还可能与以下原因有关。

2.子宫的因素：包括子宫本身的畸形、内膜息肉、子宫粘膜下肌瘤、宫腔粘连等因素，影响宫腔环境、子宫内膜厚度及容受性，导致胚胎着床失败。

3.母体的激素水平、免疫水平可能也参与了生化妊娠的发病。

4.精神过度紧张、心理压力过大也是不利于妊娠的。

**三、生化妊娠该怎么处理了？**

由于生化妊娠又称不明部位妊娠，因此我们无法判断妊娠部位是否在宫腔。一般生化妊娠均表现为月经样出血，不影响再次妊娠。

对于生化妊娠而言没有特定的处理方式，首先最重要的是确保 HCG 水平下降到非妊娠状态水平以确定排除异位妊娠，同时尽量使自己的心理负担最小化，处理后必须进行及时地随访。
