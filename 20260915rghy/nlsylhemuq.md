# 在深圳做第三代试管婴儿需要花费多少钱？

> 更新时间：2026-09-15 (UTC+8)

在深圳做第三代试管婴儿的费用因多种因素而异，包括医院级别、医生经验、治疗方案以及患者的具体情况等。根据公开发布的信息，大致的费用范围如下：

 

 一、基本费用概览

 

在深圳，第三代试管婴儿的基本费用通常包括以下几个方面：

 

| 费用项目 | 费用范围（人民币） |

| --- | --- |

| 术前检查 | 4000~30000元 |

| 促排卵药物 | 5000~50000元 |

| 取卵手术 | 一般包含在试管手术费用中，不单独计算 |

| 胚胎培养 | 10000~20000元 |

| 胚胎筛选（如PGS/PGD） | 10000~50000元 |

| 胚胎移植 | 6000~15000元 |

| 保胎药物及移植后检测 | 约1000~2000元 |

| 胚胎保存费（每年） | 约5000元 |

| 冷冻胚胎复苏费 | 约15000元 |

| 精子/卵子/胚胎冷冻费 | 8000~12000元 |

| 杂费（如挂号费、B超检查费等） | 1~2万元 |

 

 二、总费用估算

 

综合以上各项费用，深圳做第三代试管婴儿的总费用大致在10万至30万元人民币之间，甚至可能更高。具体费用会根据患者的个体情况（如年龄、身体状况、不孕原因等）、所选医院以及治疗过程中的具体情况而有所不同。

 

 三、注意事项

 

1. 医保：自2024年10月起，深圳正式将辅助生殖技术范围，但具体比例和限额需根据医保和个人参保情况确定。

2. 医院选择：不同医院的收费标准和服务质量可能存在差异，建议患者在选择医院时充分考虑医院的专业水平、设备条件、医生经验以及患者口碑等因素。

3. 个性化治疗：由于每位患者的情况不同，治疗方案和费用也会有所差异。因此，在治疗前与医生进行充分沟通，制定个性化的治疗方案是非常重要的。

 

综上所述，深圳做第三代试管婴儿的费用相对较高，但具体费用会因多种因素而异。患者在选择医院和治疗方案时，应充分了解相关信息，做好经济准备，并保持积极的心态面对治疗过程。
