# 科普丨红斑狼疮你了解多少？

> 更新时间：2026-09-16 (UTC+8)

近期，“红斑狼疮”相关词条频繁冲上热搜，引发广泛讨论。

红斑狼疮虽然听起来像皮肤病，但它其实是一类慢性、反复发作的自身免疫性疾病的总称，常见于女性，尤其是20~40岁的女性。**具体病因尚不明确，遗传、激素、免疫和环境等多重因素对发病都有影响。**

**0****1****系统性红斑狼疮有哪些症状？**

系统性红斑狼疮是一种系统性自身免疫疾病，可导致肾脏、心血管、肺、消化系统、血液系统、血管、眼部等多器官损伤。最明显的症状就是面颊出现“蝶形红斑”。

红斑狼疮常见的症状，主要有以下4种：

**01皮肤损害**

脸部皮肤出现红斑，嘴唇、口腔、舌头出现溃疡，有合并感染并剧烈疼痛，可能是红斑狼疮。

**02头发脱落、断裂**

特别是短期内突然出现广泛性的脱发，且头发比较脆，容易折断。

**03全身疼痛、不明原因发热**

出现不明原因的关节疼痛、持续性发热、对光过敏、全身乏力。

**04神经问题**

头痛、意识模糊和记忆丧失，当红斑狼疮影响大脑时，可能会出现这些神经系统症状。

只不过，红斑狼疮的早期症状往往不典型，可以出现多种疾病表现。如果日常有一些身体不适的症状，建议及时就医，以免耽误病情。

**0****2****为什么女性患者更常见？**

红斑狼疮在女性中更为常见，科学家发现可能是雌激素造成的。

虽然还没有证据证明，雌激素或任何其他激素与狼疮之间有直接的因果关系，但许多女性在月经前期或怀孕期间，当雌激素水平较高时，红斑狼疮症状更为严重，这表明激素可能在调节红斑狼疮活动中起到一定的作用。

**0****3****红斑狼疮是绝症吗？**

红斑狼疮在我国是一种常见的慢性病，虽难以治愈，但并不是一个不治之症。

随着医学的发展，临床上已经有一些药物可以有效缓解病情，让患者可以过正常人的生活，也可以上班工作。

很多患者经过正规有效的个体化治疗，可以将疾病控制在稳定状态，几年甚至数十年不发作。

**0****4****4个有关红斑狼疮的常见认识误区**

**0****1**
**红斑狼疮患者一定有面部红斑？**

不一定。

红斑狼疮患者的免疫系统会无差别攻击全身器官，因此红斑狼疮的症状多样化，只是皮肤尤其是面部皮肤受到更多人关注，因此脸部红斑往往最先被人注意到。

**0****2**
**红斑狼疮具有遗传倾向，患者不能生孩子？**

不一定。

红斑狼疮本身并不影响患者的生育能力，只是为了避免母胎面临的风险，需要提前计划生育，因为妊娠期禁用许多红斑狼疮的治疗用药。

此外，红斑狼疮本身不是遗传性疾病，但有一定的遗传倾向，是红斑狼疮患者需要考虑的问题。也就是说，如果家里有人得过红斑狼疮，那么孩子可能更容易得。

**0****3**
**红斑狼疮患者需要终身使用激素？**

不一定。

激素治疗是控制红斑狼疮的一种方法，但并非所有患者都需要终身使用。治疗方案应根据病情的严重程度和个体差异来定。

**0****4**
**红斑狼疮好了就可以自行停药？**

不是。

红斑狼疮是一种慢性疾病，可能会有复发的风险。患者可以停药，但绝对不能自行停药。请信任医生，治疗和药物使用需要遵循医生的建议。
